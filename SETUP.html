ARK RECORDS

Aktifkan arsip pribadimu.

Repo dan push kamu lakukan sendiri. Aplikasi ini tidak membutuhkan instalasi paket atau server berbayar.

1. Terbitkan di GitHub Pages

  1. Buat repository public, misalnya ark-records.
  2. Upload isi folder paket ini ke akar repo, sehingga index.html ada langsung di halaman utama repo. Jangan upload ZIP saja.
  3. Buka Settings → Pages. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
  4. Tunggu status deployment berhasil. Link biasanya berbentuk https://USERNAME.github.io/ark-records/. Gunakan link yang benar-benar ditampilkan GitHub.

Kode dan halaman awal bersifat publik. Tidak ada arsip pribadi atau password dalam repo. Jangan pernah mengunggah file .arkbackup ke repo.

2. Buat proyek Google

  1. Buka Google Cloud Console dengan akun Google milikmu.
  2. Buat proyek bernama ARK RECORDS.
  3. Buka APIs & Services → Library, cari Google Drive API, lalu pilih Enable.
  4. Buka Google Auth Platform atau OAuth consent screen. Isi nama aplikasi dan email dukungan milikmu.
  5. Pilih audience External untuk Gmail pribadi, dan biarkan status Testing.
  6. Di bagian Test users, tambahkan hanya alamat Gmail kamu sendiri. Akun ini yang dipakai dari HP dan laptop.
  7. Di Data Access / Scopes, tambahkan https://www.googleapis.com/auth/drive.appdata. Aplikasi tidak memerlukan izin seluruh Drive.

Nama menu dapat sedikit berubah. Gunakan proyek Google yang sama untuk pemakaian selanjutnya, agar arsip tetap terhubung ke aplikasi yang sama. Tidak perlu membeli paket hosting; kuota dan ketentuan Google tetap berlaku.

3. Buat OAuth Client ID

  1. Masuk ke Clients → Create client atau Credentials → Create credentials → OAuth client ID.
  2. Pilih Web application.
  3. Tambahkan Authorized JavaScript origins: https://USERNAME.github.io. Ganti USERNAME dengan username GitHub-mu, tanpa nama repo dan tanpa tanda slash di belakang.
  4. Untuk uji lokal opsional, tambahkan http://localhost:4173 dan http://127.0.0.1:4173.
  5. Aplikasi memakai popup Google. Tidak perlu menambah redirect URI untuk alur ini.
  6. Salin Client ID yang berakhiran .apps.googleusercontent.com. Jangan salin Client Secret.

4. Hubungkan aplikasi

  1. Buka website ARK RECORDS.
  2. Tempel Client ID pada kolom yang tersedia, kemudian pilih Simpan konfigurasi.
  3. Pilih Hubungkan Google Drive. Login menggunakan akun yang terdaftar sebagai test user dan setujui izin data aplikasi.
  4. Tambahkan seseorang. Setelah muncul Tersimpan di Google Drive, buka link dari HP dan hubungkan akun yang sama.
  5. Untuk menghindari memasukkan Client ID di setiap perangkat, isi googleClientId di config.js, lalu push ulang. Client ID adalah konfigurasi publik, bukan password.

Aplikasi tetap terkunci sebelum terhubung. Token login hanya berada di memori halaman; setelah menutup atau memuat ulang halaman kamu perlu menghubungkan lagi. Saat token berakhir, tombol sambungkan kembali akan muncul. Draf yang belum disimpan tidak bertahan setelah halaman ditutup.

5. Pahami penyimpanan

  • Arsip menggunakan appDataFolder: ruang aplikasi privat dalam akun Drive-mu, bukan folder biasa yang terlihat di My Drive. Data tetap menggunakan kuota Drive.
  • Halaman website publik tidak membuat data Drive publik. Orang lain tidak mendapat akses ke arsipmu dari link website.
  • Data tidak dienkripsi ujung-ke-ujung oleh ARK. Privasi bergantung pada keamanan akun Google dan izin Drive.
  • Jangan menghapus data aplikasi ARK melalui pengaturan Google Drive atau menghapus proyek Google tanpa backup.
  • Tombol Kunci & keluar membersihkan sesi lokal. Ini tidak mengeluarkan akun Google dari browser dan tidak mencabut persetujuan aplikasi.
  • Gunakan Muat ulang dari Drive untuk melihat perubahan dari perangkat lain. Jika dua perangkat menyimpan bersamaan, pilih versi yang ingin dipertahankan.
  • Setelah menghapus profil/media, gunakan Pengaturan → Bersihkan riwayat & media terhapus untuk menghapus file lama secara permanen. Tutup aplikasi di perangkat lain lebih dahulu.

Backup dan batas versi awal

Ekspor dari Pengaturan menghasilkan .arkbackup berisi data, foto, dan video asli. File ini tidak dienkripsi. Simpan secara pribadi, bukan di repo GitHub. Impor menambahkan salinan dengan identitas baru dan tidak menimpa arsip lama.

  • Maksimal 50 MB per file media.
  • Maksimal 100 MB per file backup, termasuk encoding media. Ini batas pemrosesan backup di browser, bukan batas total Drive.
  • Video MOV bisa diunggah, tetapi pemutaran bergantung pada codec browser. MP4 atau WebM lebih praktis.
  • Asisten menggunakan aturan sederhana, bukan AI generatif. Tidak menerjemahkan semua istilah kesukaan secara otomatis.
  • Versi ini memerlukan internet untuk membaca dan menyimpan. Tidak menyimpan salinan arsip permanen di browser.
  • Untuk banyak ribuan profil/versi, pemuatan akan melambat. Bersihkan riwayat setelah backup.

Jika login gagal

  • origin_mismatch: pastikan origin persis sama, termasuk HTTPS, dan tidak menyertakan path repo.
  • access_denied: periksa test user, akun yang dipilih, dan izin scope.
  • Popup tidak terbuka: izinkan popup untuk situs ARK, periksa pemblokir script, lalu coba lagi.
  • Drive belum aktif: aktifkan Google Drive API pada proyek yang memiliki Client ID.
  • Akun berubah: kunci & keluar dahulu, baru hubungkan akun berbeda. Simpan draf di akun semula sebelum beralih.
  • Data kosong di perangkat lain: periksa akun Google dan Client ID/proyek yang dipakai, lalu muat ulang Drive.
